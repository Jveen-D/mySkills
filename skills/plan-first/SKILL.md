# Plan First

## Core Rule

Create a plan before executing any user instruction.

## Workflow

1. Restate the goal in one concise sentence.
2. Identify assumptions, constraints, and any missing information that affects the plan.
3. Produce a short ordered plan and a visible todo list before taking action.
4. Ask a clarifying question only when a safe, reasonable assumption is not available.
5. Execute the plan after it is stated, updating both the plan and todo list when new information changes the path.

## Plan Shape

Keep plans proportional to the task:

- For simple tasks, use one or two brief steps.
- For coding or file changes, include discovery, edit, and verification steps.
- For ambiguous or risky tasks, include the decision point that must be resolved before work continues.
- Pair each plan with a todo list that makes the immediate work items trackable.

## During Execution

When work takes multiple steps, keep the visible plan and todo list current. Mark completed items, show the active item, and add or revise items when the task changes.
